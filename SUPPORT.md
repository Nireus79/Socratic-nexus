# Support

This library is part of the earlier Socrates research prototype and is not maintained as a product.

- Questions and bug reports: open an issue at https://github.com/Nireus79/Socratic-nexus/issues
- Contact: Hermes_creative@proton.me

When you report a problem, include:

- the Python version and the output of `pip show socratic-nexus`
- the smallest code sample that shows the problem
- the full error message (remove any API key first)

Your provider's own documentation covers account, key and rate-limit questions.
